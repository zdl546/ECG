# ECG
## Dataset
Two public ECG datasets are used in this work:
1. [PTB-XL v1.0.3](https://physionet.org/content/ptb-xl/1.0.3/)
   Source: PhysioNet, License: CC BY 4.0
   > Wagner P, Strodthoff N, Bousseljot RD, et al. PTB-XL, a large publicly available electrocardiography dataset. Sci Data. 2020;7:154.
   > Wagner P, Strodthoff N, Bousseljot R, Samek W, Schaeffter T. PTB-XL, a large publicly available electrocardiography dataset (version 1.0.3). PhysioNet. 2022.

2. [Mendeley ECG Image Dataset V2](https://data.mendeley.com/datasets/gwbz3fsgp8/2)
   Source: Mendeley Data, License: CC BY 4.0
   > Khan AH, Hussain M, Malik MK. ECG Images dataset of Cardiac and COVID-19 Patients. Data Brief. 2021;34:106762.
   > Khan AH, Hussain M. ECG Images dataset of Cardiac Patients. Mendeley Data. Version 2. 2021.

Full datasets are obtained from the official links above.
